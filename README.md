# 🏭 ChurrosCompanyHierarchy

Un proyecto en Java que modela la estructura organizacional de una empresa de churros utilizando el patrón de diseño **Composite**. Permite representar jerarquías anidadas de empleados y secciones de la empresa como una estructura de árbol.

---

## 🎯 Objetivo

El propósito de este proyecto es demostrar cómo el **patrón Composite** puede utilizarse para modelar jerarquías complejas, permitiendo tratar a objetos individuales (empleados) y compuestos (secciones de la empresa) de forma uniforme.

Este patrón es ideal para estructuras organizacionales, menús, carpetas de archivos, etc.

---

## ⚙️ Funcionalidad

- Modela una empresa con diferentes niveles jerárquicos usando composición.
- Se pueden crear secciones que contengan otras secciones o empleados.
- Permite generar y visualizar una jerarquía completa desde la raíz.
- Los empleados no pueden contener sub-secciones (lanzan excepción si se intenta).

---

## 🛠️ Tecnologías usadas

- Java 17+
- IntelliJ IDEA
- POO (Programación Orientada a Objetos)
- Patrón de diseño: Composite
